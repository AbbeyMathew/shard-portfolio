# Shard Box Portfolio

An interactive 3D developer portfolio built with React, Vite, Three.js, and JavaScript. Showcasing my projects, skills, and experiments through a futuristic shard-based interface.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

- **GitHub:** create a repository and push this project.
- **Render Static Site:** connect the repository, set **Build Command** to `npm install && npm run build`, and **Publish Directory** to `dist`.

Three.js is currently loaded from the same CDN URL as the original HTML. Google Fonts are also loaded remotely, as in the original.

Project titles and URLs remain the original placeholders intentionally; nothing has been personalised or redesigned.
